# มหาวิทยาลัยแห่งท่าศาลา

เกมสร้างและบริหารมหาวิทยาลัยบนผัง OpenStreetMap จริง เริ่มจากที่ดินว่างใน พ.ศ. 2541 เป้าหมายคือนักศึกษา 10,000 คนและชื่อเสียง 80

รันจากโฟลเดอร์นี้ด้วย `python3 tools/serve.py 8000` แล้วเปิด http://localhost:8000 ไม่ต้องติดตั้งแพ็กเกจหรือบิลด์ ใช้เบราว์เซอร์สมัยใหม่ที่รองรับ ES modules

- เลือกอาคารด้านซ้าย แล้วคลิกวางบนหญ้า โดยขอบต้องติดถนน เริ่มด้วยอาคารบริหาร
- ลากแผนที่ / WASD / ปุ่มลูกศรเพื่อเลื่อน ล้อเมาส์หรือปุ่ม + − เพื่อซูม ปุ่มดูทั้งพื้นที่เพื่อจัดมุมมอง
- บนมือถือ ลากเพื่อเลื่อน แตะเพื่อสร้าง ใช้ปุ่ม + − เพื่อซูม เมนูอยู่ใต้แผนที่
- Esc ยกเลิกเครื่องมือ คลิกอาคารเพื่ออ่านข้อมูล เลือกรื้อถอนเพื่อคืนเงิน 30%
- เปิดแสดงผังจริงเพื่อดูกรอบอาคารอ้างอิง วางชนิดตรงกันทับพื้นที่อย่างน้อย 50% ของกรอบหรืออาคาร ได้ผลลัพธ์เพิ่ม 10% และชื่อเสียง +2 ครั้งเดียวต่อจุด (รื้อแล้วสร้างใหม่ไม่เพิ่มซ้ำ)
- กดจบเทอม หรือเลือกความเร็ว 1× (10 วินาทีต่อเทอม) / 2× (5 วินาที) บันทึกและโหลดผ่านพื้นที่จัดเก็บของเบราว์เซอร์

ค่าเล่าเรียน 2,400 บาท/คน/เทอม ค่าใช้จ่ายนักศึกษา 650 บาท/คน/เทอม นอกเหนือค่าดูแลอาคาร จบการศึกษา 20% ทุกสิ้นปี มี 3 เทอมต่อปี ที่นั่ง +400 เตียง +300 อาหาร +600 ต่ออาคาร อาคารวิชาการเพิ่มความจุหลักสูตร 2,000 คนจากฐาน 1,200 คน ห้องสมุดรองรับ 1,800 คน ศูนย์กีฬา 2,000 คน โรงพยาบาลราคา 2.4 ล้านบาท ปลดล็อกที่ชื่อเสียง 60 ดูราคาและค่าดูแลอาคารได้ในเกม

สร้างแผนที่ใหม่: `python3 tools/build_map.py` (อ่าน `data/` เท่านั้น; เขียน `src/map-data.js`) ตรวจสอบระบบจำลอง: `node --test tests/sim.test.mjs` (Node 24 ไม่รองรับการส่งชื่อโฟลเดอร์ `tests/` โดยตรง) ใช้ seeded RNG และฟังก์ชันที่คืนสถานะใหม่โดยไม่แก้สถานะเดิม

## เนื้อเรื่องและภารกิจ (v2)
- เล่นตามเนื้อเรื่อง 6 บท = 6 เลเวล (พ.ศ. 2535 → 2565) แต่ละบทมีภารกิจ รางวัล และปลดล็อกอาคารใหม่ — ข้อมูลอยู่ใน `src/story.js`
- แผนที่มีแค่ถนนสายหลักจริง ถนนอื่นผู้เล่นสร้างเอง (เครื่องมือ "ถนน" ลากเพื่อสร้าง) จุดจางคือแนวถนนเดิม สร้างทับได้ครึ่งราคา
- อาคารต้องติดถนนที่เชื่อมไปถึงถนนสายหลัก
- คลิกขวาค้างแล้วลาก (หรือ Option+ลาก) เพื่อหมุนกล้องอิสระและปรับมุมก้ม • ขณะใช้เครื่องมือถนน เลื่อนแผนที่ด้วยปุ่มกลางหรือ WASD
- `node --test tests/sim.test.mjs` มีบอทเล่นจบทั้ง 6 บทเพื่อตรวจสมดุลเกม

## 3D และชีวิตตัวละคร (v3)
- มุมมอง 3D isometric (Three.js โหลดจาก CDN จึงต้องต่ออินเทอร์เน็ต) • Q/E หรือปุ่ม ⟲ ⟳ หมุนกล้อง • ล้อเมาส์ซูม • ลากเพื่อเลื่อน
- มีกลางวัน/กลางคืน ไฟหน้าต่างเปิดตอนค่ำ
- นักศึกษาเดินบนถนนตามตารางชีวิต: ตื่น → กินข้าว → เรียน → กินข้าว → เรียน/ห้องสมุด → กีฬา → กินข้าว → พักที่หอ → นอน (`src/life.js`)
- แต่ละคนมีชื่อ คณะ ชั้นปี ความหิว พลังงาน ความสนุก ความเครียด และความคิด คลิกตัวละครเพื่อดู หรือกด "ติดตามตัวละคร"
- อาคารที่คนเต็มจะเห็นคนต่อคิวหน้าประตู อารมณ์เฉลี่ยของนักศึกษาในเทอมนั้นมีผล 30% ต่อความพึงพอใจ
- 1 ตัวละครแทนนักศึกษาราว 20 คน (สูงสุด 300 ตัว)
- เวอร์ชัน 2D เดิมเก็บไว้ที่ `legacy/main2d.js`

## สาธารณูปโภคและเครือข่าย
- วางโรงผลิตน้ำประปาและสถานีไฟฟ้าย่อย แล้วลากท่อหรือสายไฟให้แตะขอบอาคารเพื่อจ่ายน้ำและไฟ อาคารที่ขาดอย่างใดอย่างหนึ่งจะหยุดให้บริการ
- สร้างศูนย์ดิจิทัลเพื่อปลดล็อกจุดกระจาย Wi-Fi วาง AP ติดสายไฟหรืออาคารที่มีไฟฟ้า วงแหวนในมุมมองสาธารณูปโภคแสดงระยะครอบคลุม
- ท่อและสายไฟมีค่าก่อสร้าง/ดูแลรายเทอม และรื้อได้ด้วยเครื่องมือรื้อถอน
